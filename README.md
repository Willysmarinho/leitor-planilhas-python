# Leitor de Planilhas em Python

Script que lê uma planilha de vendas (`vendas.csv`), calcula o total por produto e gera uma nova planilha com o resultado.

## Tecnologias
- Python 3 (somente bibliotecas padrão: `csv`, `collections`)

## Como rodar
```bash
python leitor.py
```
Ou informando os arquivos:
```bash
python leitor.py vendas.csv total_por_produto.csv
```

## Exemplo de saída
```
caderno: R$ 94.50
caneta: R$ 37.50
lapis: R$ 24.00
Planilha gerada: total_por_produto.csv
```

Leitura e escrita de arquivos, dicionários, funções e manipulação de dados.
